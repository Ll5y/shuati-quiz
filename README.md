# 答题练习（构建产物）

这个仓库只存放**编译压缩后的成品文件**，是 https://ll5y.github.io/shuati-quiz/ 的部署源。

- 在线使用：https://ll5y.github.io/shuati-quiz/
- 单文件版：https://ll5y.github.io/shuati-quiz/standalone.html （可下载离线打开，也可直接发给别人）

功能：单选 / 多选 / 判断 / 填空四种题型，练习模式即时判分 + 解析，考试模式统一判分；
支持自建题库、粘贴文本导入、导入 Word（.docx）；进度、错题、收藏保存在本机浏览器，
不上传任何服务器。

> 仓库内仅有压缩混淆后的代码，可读源码不公开。

构建产物由源码仓库自动生成，请勿直接改这里的文件——下次发布会被覆盖。
