答题练习（电脑版）· 使用说明
================================

【怎么打开】
  双击本文件夹里的 index.html，用 Edge 或 Chrome 打开即可。
  不用安装、不用联网、不用起服务器。

  standalone.html 是「单文件版」：样式和脚本全部内联在一个 HTML 里，
  内容和 index.html 完全一样。发给别人、或者放到只支持单文件的预览环境里用它。
  （两个文件都改了代码后，跑 tools/build-standalone.py 重新生成 standalone.html）

【第一次用】
  1. 左边选题库：默认没有任何题库，先点「导入题库」（读 .docx / 粘贴文本）或「手动新建」建一个
  2. 右边选模式：练习模式（每题即时判分）或 考试模式（全部答完统一判分）
  3. 选本轮题量，点「开始答题」

【答题规则】
  题型：单选 / 多选 / 判断 / 填空

  · 点「下一题」不会拦你：什么都没填也不算错操作，但会当场判为错误并展开本题答案
    （输入框标红 + 参考：1. …　·　2. …，答题卡标红），提示「本题未作答，已记为错误」；
    看过答案后再点一次「下一题」才真正进入下一题。
   · 点「提交答案」立刻判分：答对停 0.6 秒后自动进入下一题；答错停在本题并展开答案。
  · 填空题只有一个输入框：几个空的答案用逗号或空格分开，例如「电伤，电击」；顺序任意，倒着填也算对。
  · 判错之后输入框还能直接改，答案也一直留在这一题上；改完再点「提交答案」
    就按新答案重新判一次。不想改了，点「下一题」往下走即可。
   · 切换到别的题时，上一题的答案和红绿标记不会残留到新题上。

  键盘：A–D 选选项，← → 上一题 / 下一题，Enter 提交答案 / 下一题，
        答题页左下角有「结束答题」按钮，随时可以结束本轮（进度会保存）。

【收藏题练习】
答题时点右上角的「☆ 收藏」，这题就收进「收藏题」里（可以跨题库收藏）。
回主界面，「答题设置」最上面会多出「☆ 收藏题练习 ②」，点它就能把收藏的题集中练一遍。
还没收藏过时这个按钮是灰的，旁边会提示怎么收藏。

【自己加题库】
  自定义题库 → 新建：逐题手填（题干、选项、正确答案、解析）
  自定义题库 → 导入：粘贴文本，或直接选 .docx / .json 文件

  .docx 支持的写法（小节标题会当成章节名）：

    一、填空题
    1.人体触电有（电伤）和（电击）两类。          答案已经填在括号里也认
    2.间接接触触电包括（　）触电、（　）触电等。 用（　）留空
    答案 单相|两相                              | 分隔不同的空
    答案 单相|单相触电/单相电击                 / 分隔同一空的同义写法
    解析 ……                                     可省略

  只认 .docx（新格式）。老 .doc 请先在 Word 里「另存为 .docx」。
  题目如果放在图片或表格里，取不到文字，会提示「没解析出题目」。

【数据存在哪】
  答对答错、错题本、收藏、自定义题库都存在浏览器本地（localStorage），
  键名 quiz.app.v1 和 quiz.customBanks.v1，不上传任何服务器。
  换浏览器或清理浏览器数据会丢记录；要备份就用「自定义题库 → 导出」存成 .json。

【想改代码】

手机上怎么用
============

这个页面已经适配手机屏幕：单列布局、按钮 44px 高、底部固定「上一题 / 结束答题 / 下一题」，
也可以装成手机上的一个 App 图标（PWA）。

【最省事】只用一个文件
  1. 把 standalone.html 通过微信/QQ/数据线传到手机
  2. 用手机浏览器（Chrome / Edge / Safari）打开它
  3. 即可正常答题；缺点是没法生成桌面图标，每次要从文件管理器打开

【推荐】手机和电脑连同一个 WiFi
  1. 电脑上在这个文件夹里执行：python -m http.server 8000
  2. 查电脑的局域网 IP（Windows: ipconfig，找 192.168.x.x）
  3. 手机浏览器打开 http://192.168.x.x:8000
  4. 安卓 Chrome / iOS Safari 菜单里选「添加到主屏幕」，图标就和 App 一样
  5. 装好后断网也能打开（页面已离线缓存）
  注意：手机和电脑要在同一个网络；电脑关机后打不开，但已装到桌面且缓存过的仍可离线用

【最稳】放到静态网站
  把整个文件夹（index.html、manifest.webmanifest、sw.js、css、js、assets）传到
  GitHub Pages / Cloudflare Pages / Vercel 任意一个，手机打开网址再「添加到主屏幕」，
  就是完整可安装的 PWA，不依赖电脑开机。

数据说明
  答题进度、错题本、自定义题库都存在「当前这台设备、这个浏览器」里，
  换设备或清浏览器数据会丢；想留档可以用首页的「导出 JSON」把题库导出保存。
